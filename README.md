# 通用项目模板

这是一个用于后续接入实际工程的通用项目模板。

当前仓库主要用于搭建一套可复用的开发工作流、opencode 配置以及代理协作约定。后续可以根据具体工程类型，逐步补充业务代码、构建脚本、测试命令和部署流程。

## 当前用途

- 作为通用工程起点
- 作为 opencode 工作流模板
- 作为后续迁移到具体项目时的基础骨架

## 当前包含内容

- `AGENT.md`：项目通用代理工作约定
- `CLAUDE.md`：Claude 系列代理工作约定
- `opencode.json`：opencode 的基础配置
- `.opencode/agents/`：主代理与子代理模板
- `.opencode/skills/`：日常开发工作流模板
- `.opencode/command/`：常用命令模板

## 使用方式

1. 按需要补充实际工程代码。
2. 根据技术栈修改 `opencode.json` 中的模型、权限和代理配置。
3. 根据真实项目补充或替换 `.opencode/agents/`、`.opencode/skills/`、`.opencode/command/`。
4. 将本文件中的说明替换为真实项目的安装、运行、测试与发布说明。

## 后续建议补充的内容

当这个模板落到具体工程后，建议补充以下内容：

- 项目简介
- 技术栈说明
- 目录结构
- 环境要求
- 安装步骤
- 本地运行方式
- 测试与验证命令
- 构建与发布流程
- 常见问题
- 贡献说明

## 说明

这个仓库当前是通用型模板，不绑定任何具体业务或框架。后续所有内容都可以按实际工程调整。
