---
description: 显示当前工作区差异（含已暂存），便于审查与汇报。
---

依次执行下列命令，并用中文做结构化总结：

```bash
git diff --stat
git diff --stat --cached
git diff
git diff --cached
```

汇报要求：

- **变更概览**：共 N 个文件，+X / -Y 行
- **按文件分组**：每个文件用 1–2 句话说明改了什么意图
- **风险信号**：是否触及配置 / schema / 公开 API / 安全相关代码
- **建议**：
  - 是否需要委派 `review` 子代理
  - 是否需要补测试
  - 是否需要拆成多次 commit

> 如果 diff 过大（> 500 行），仅总结**最关键的 3–5 个文件**，其余用一句话概括，避免输出爆炸。
